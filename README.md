# Sutido Flavia Marin

Site estático de perfumaria, pronto para publicar no GitHub Pages.

## Como usar

Abra o `index.html` no navegador ou publique este repositório em **Settings → Pages → Deploy from branch**.

O botão **Acesso administrativo** no rodapé abre o painel de produtos. Ele permite cadastrar, editar, excluir, definir categoria, preço, foto por URL e promoção. Os dados ficam salvos no `localStorage` do navegador, então esse painel é ideal para protótipo ou administração local. Para alterações públicas em todos os dispositivos, conecte o formulário a um backend/CMS.

## Personalização rápida

- Dados de contato: edite o rodapé em `index.html`.
- O catálogo começa vazio. Cadastre os produtos pelo painel administrativo no rodapé.
- Cores e layout: edite as variáveis no início de `styles.css`.
- Para fotos, use URLs públicas HTTPS no painel ou coloque imagens na pasta do projeto e informe o caminho relativo (ex.: `assets/meu-perfume.jpg`).
